## H1. Show a weight in pounds

An admin screen shows weights in pounds. A record holds the text `82 kg`. Write `h1.mjs`, and
report the call and the number of pounds.

## H2. Read a height written in words

A voice form writes what users say as text, such as `six foot one`. Write `h2.mjs`, which reads
it as a height, and report the call and its result.

